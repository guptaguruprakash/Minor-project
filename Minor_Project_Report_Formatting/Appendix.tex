\begin{flushleft}
\textbf{A.1 Software and Model Files}

The project source is organized into the following files:
\begin{itemize}
	\item \texttt{esp32\_dual\_mpu6050\_post.ino}: sensor acquisition, buffering, OLED display, and HTTP upload.
	\item \texttt{model.ino}: adapter functions for embedded KNN prediction.
	\item \texttt{train\_knn.py}: CSV loading, feature scaling, prototype selection, and header generation.
	\item \texttt{knn\_model.h}: generated model data and prediction function.
	\item \texttt{fastapi\_api/app/main.py}: data receiver, live prediction API, and CSV storage.
\end{itemize}
\end{flushleft}
