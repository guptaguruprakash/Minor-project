\chapter{CONCLUSION}

This project presents a low-cost smart gym assistant for monitoring exercise movement and posture. Two MPU6050 sensors collect acceleration and gyroscope measurements, while the ESP32 prepares the sensor data and performs local K-nearest neighbors classification. The current implementation focuses on bicep curls and squats and can identify the exercise and posture class from labeled motion data.

The system combines live batch prediction with repetition-counting logic and immediate feedback through an OLED display and buzzer. In collection mode, labeled sensor batches are sent to the FastAPI service for storage and later model training. In live mode, the ESP32 keeps the prediction process local and publishes the latest exercise, posture, confidence, and repetition information to the web monitor.

The prototype demonstrates that wearable inertial sensors and a compact machine-learning model can provide practical exercise feedback on resource-constrained hardware. Its performance still depends on consistent sensor placement, representative training data, and balanced posture classes. Future work can include additional exercises such as push-ups, more users and movement styles, improved repetition-counting thresholds, and comparison with quantized neural-network models.
