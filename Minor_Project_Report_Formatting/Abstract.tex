\chapter*{ABSTRACT}
\addcontentsline{toc}{chapter}{ABSTRACT}

The Smart Gym Assistant is a low-cost wearable exercise-monitoring system designed
to recognize exercise movements, identify posture quality, count repetitions, and
provide immediate feedback. The system uses two MPU6050 inertial sensors connected
to an ESP32 microcontroller. Acceleration and gyroscope readings from both sensors
form a twelve-feature input vector for a compact K-nearest neighbors classifier.

The ESP32 standardizes the sensor features, performs local KNN inference, and uses
batch voting to produce stable exercise and posture predictions. An OLED display
and buzzer provide local feedback, while a Wi-Fi connection sends collection data
and live results to a FastAPI service and browser dashboard. The training pipeline
cleans labeled CSV data, evaluates prototype counts and neighbor values, and exports
the selected model to an embedded header file.

The evaluated classes include bicep bad, bicep good, bicep idle, squat bad, squat
good, and squat idle. The results show strong recognition of idle classes, with F1-
scores above 94\%, while posture classes remain more challenging because good and
bad movement patterns can overlap. The system demonstrates that wearable inertial
sensing and lightweight machine learning can provide practical exercise feedback on
resource-constrained hardware.
